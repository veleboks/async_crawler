# async_crawler

Учебный асинхронный веб-краулер на Python. Проект нужен мне для практики `asyncio`, `aiohttp`, управления конкурентностью и работы с очередями.

## Что уже умеет

- параллельно загружать несколько страниц через одну `aiohttp.ClientSession`;
- ограничивать общее количество запросов и количество запросов к одному hostname;
- ограничивать частоту начала запросов через `RateLimiter`;
- обходить найденные ссылки с ограничением глубины и количества страниц;
- не добавлять один URL в очередь повторно;
- разбирать HTML через BeautifulSoup и lxml;
- извлекать текст, заголовок, метаданные, ссылки и изображения;
- преобразовывать относительные ссылки в абсолютные;
- обрабатывать сетевые ошибки и таймауты;
- выводить логи и базовую статистику обхода.

## Запуск

Проект использует Python 3.13 и пакетный менеджер [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python examples/simple_fetch.py
uv run python examples/simple_parse.py
uv run python examples/simple_crawl.py
```

Тесты и проверка форматирования:

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
```
